# 🌱 StorySeed

**Plant 3 words. Grow a story.**

StorySeed is a simple local AI story generator powered by Tether's QVAC SDK. Enter three random words and StorySeed creates a short original story using those words.

## Features

- Enter 3 words as story seeds
- Generate a short creative story
- AI runs locally using QVAC
- No cloud AI API required
- No API key required
- Simple web interface

## Technology

- JavaScript
- Node.js
- Express
- QVAC SDK `@qvac/sdk@0.19.1`
- Model: `LLAMA_3_2_1B_INST_Q4_0`

## Requirements

- Node.js 18 or newer
- npm
- A computer capable of running the QVAC model
